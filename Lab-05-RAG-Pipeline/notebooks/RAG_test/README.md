# Lab 05 – Retrieval-Augmented Generation (RAG) Pipeline


Module: PUSL3205 – Large Language Models and Generative AI
Objective
Implement a Retrieval-Augmented Generation pipeline that retrieves relevant information from documents and generates document-grounded responses using a Large Language Model.
Technologies
- Python
- LangChain
- ChromaDB
- Ollama
- Streamlit
Implementation
The implementation is available in the RAG_test project folder.
Project Files
File	Description
app.py	Streamlit user interface
ingest.py	Document ingestion and processing
rag_pipeline.py	Retrieval and response generation
requirements.txt	Required Python dependencies
data/	Source documents

Installation
Install the required Python dependencies:
pip install -r requirements.txt


The virtual environment and generated vector database are excluded from version control.
